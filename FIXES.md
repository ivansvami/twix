# Исправления twix

Проверено и исправлено:

- Восстановлена отрисовка карточек ленты в `views/feed.ejs` — раньше `<div class="grid">` оставался пустым.
- Исправлено отображение YouTube-видео в карточках и внутри страницы/модалки поста через iframe.
- Исправлена передача категории в API предложенных YouTube-видео.
- Добавлена проверка родительского комментария: ответ теперь нельзя привязать к комментарию другого поста.
- Добавлена обработка асинхронных ошибок для основных маршрутов через `middleware/asyncHandler.js`.
- Добавлен общий обработчик ошибок Express.
- Исправлена генерация `shortId`: теперь при исчерпании попыток сохранение корректно завершается ошибкой, а не создаёт неопределённый ID.
- Добавлена валидация категорий и MIME-типов загружаемых файлов.
- Исправлен XSS-риск в клиентском превью имён загружаемых файлов.
- Исправлена ссылка на favicon: использован существующий `logo.svg`, которого хватает для SVG favicon.
- Удалён старый неиспользуемый `views/index.ejs` и дублирующий `public/js/post-modal.js`, которые ссылались на отсутствующие CSS/маршруты и не использовались сервером.
- Убрана зависимость от устаревшего Node SDK ImageKit: загрузка/удаление файлов выполняется через официальный HTTP API с `fetch`, поэтому `package.json` и `package-lock.json` больше не расходятся из-за отсутствующего `imagekit`.
- Приведены `package.json` и `package-lock.json` к согласованному состоянию.
- Для session-cookie добавлены `httpOnly`, `sameSite=lax` и `secure` в production.
- `trust proxy` ограничен первым прокси вместо доверия всем заголовкам.
- Нормализованы username/email при регистрации и логине.

Проверки:

- `node --check` — все JS-файлы проходят синтаксическую проверку.
- `npm install --package-lock-only --offline` — lock-файл согласован с `package.json`.
- `npm ci --dry-run --offline` — зависимости из lock-файла разрешаются без ошибки.

- Для Vercel исправлена критическая проблема `FUNCTION_PAYLOAD_TOO_LARGE`: файлы при создании нового поста теперь загружаются браузером напрямую в ImageKit, а на сервер отправляются только URL/fileId и текстовые данные поста.
- Добавлена серверная выдача временной ImageKit upload-auth подписи.
- Добавлена полноценная обработка drag & drop в форме нового поста.
- Оставлена поддержка Ctrl+V для изображений.
- Ограничение нового поста: максимум 10 файлов; сервер дополнительно проверяет структуру полученных данных.


## YouTube-публикации

- YouTube-предложка теперь связывается с созданным `Post` через `SuggestedVideo.post`.
- В карточке YouTube добавлена кликабельная область поверх iframe: клик открывает публикацию, а не YouTube.
- В карточке появляется подсказка «Открыть публикацию».
- Удаление YouTube-публикации из страницы/модального окна работает тем же маршрутом, что и для обычных постов.
- При удалении публикации удаляется связанная запись `SuggestedVideo`; для старых записей без связи используется совпадение URL + автора.


### YouTube-публикации

- Название нового предложенного YouTube-поста автоматически берётся из YouTube через oEmbed.
- Если YouTube временно не отдаёт название, используется запасной заголовок «Предложенное видео».
- Клик по YouTube-превью в ленте открывает полноценную страницу `/post/:shortId`, а не AJAX-модалку.
- На полной странице сохраняются комментарии и действия владельца, включая удаление.
- Кликабельная область поверх превью больше не перехватывает клик у самой карточки.
